# pilot-border

A one-button arcade flyer: pilot a light along a shifting glowing border. Stay inside it. One touch outside = crash.

Play by opening the hosted page. Hold mouse / touch / Space to climb, release to dive.

## How it works

- Canvas fullscreen render, no dependencies, single `index.html`.
- The "border" is a safe band centered on a stacked-sine curve (`borderY`), scrolled by time `t`. Band half-width `gap()` shrinks as score grows, so difficulty ramps.
- Player sits at fixed `x = 30% width`; only vertical physics: thrust up while held, gravity while released, damped velocity, clamped speed.
- Collision is one check: `|playerY - borderY| > gap/2` (plus off-screen) means crash.
- Trail + spark particles, gradient sky, starfield, glow via `shadowBlur` — all canvas primitives.
- Game states: `menu` / `play`. Score = survival time × 10 (meters). Best stored in `localStorage`.
- Input unifies pointer + keyboard so desktop and mobile work with the same two handlers.

## Why these choices (step-by-step reasoning)

1. Game had to run on GitHub Pages with zero build: picked static single-file HTML with inline CSS/JS so any static host works, no bundler or assets to break.
2. Needed "playable" with minimal code: chose one-button climb/dive instead of free 2D flight — one input, one physics axis, one collision test.
3. Needed "beautiful" cheaply: gradients + sine border + glow + particles are all a few canvas calls, no images or fonts to load.
4. Needed difficulty without levels: shrinking gap + fixed speed ramp does it in one line.
5. Skipped menus, audio, multi-page, frameworks: `alert`-free overlay div covers start/retry; skipped WebAudio beeps to keep the diff small. Add when players ask.
